03 Selected work

Things I built that changed the numbers.

01 / ArchitectureJava · Flutter

1day

Configuration-driven form engine

A form configurator and renderer that launches new deployments without code changes. A new form takes a day and a new state takes a week. This is how MEDplat grew to 8 deployments.

  • Dynamic forms
  • Rule engine
  • Spring Boot
  • Flutter
02 / Applied AIWhisper · Qwen · Gemini

10×faster entry

Voice & AI-assisted data entry

Health workers speak and the form fills itself. It uses Whisper speech-to-text, an on-device Qwen model that works offline, and Gemini when a connection is available. Entry time dropped from 3–4 minutes to 20 seconds.

  • Speech-to-text
  • On-device LLM
  • Offline
03 / PerformancePostgreSQL · SQLite

30×faster sync

Offline-first sync

Offline data models with sync and conflict resolution for places with little or no network. Changes to the sync strategy and query tuning cut sync from 5 minutes to 10 seconds.

  • Conflict resolution
  • Bloc
  • Query tuning
04 / MobileFlutter · Jenkins

1codebase

Android → Flutter migration

One Flutter codebase with a shared design system, multi-flavor builds and Jenkins pipelines. All 8 deployments can release independently.

  • Design system
  • Multi-flavor
  • pub.dev packages
05 / InteroperabilityFHIR · DHIS2 · CommCare

FHIRnative

Open Health Stack

A FHIR-compliant architecture built on Google's Android FHIR SDK, with field research done alongside Sewa Rural. Patient data is protected with encryption, RBAC and audit logging.

  • Android FHIR SDK
  • Encryption
  • RBAC
