# prateekgarg.dev

Personal portfolio of Prateek Garg. Plain HTML, CSS and JavaScript with no build step, hosted on GitHub Pages.

## Files

- `index.html`: all page content (edit text here)
- `styles.css`: theme and layout (colors are variables at the top)
- `main.js`: small enhancements (mobile menu, typing effect, count-up stats, scroll reveal)
- `404.html`: not-found page
- `CNAME`: custom domain for GitHub Pages

## Local preview

Open `index.html` in a browser, or serve the folder:

```bash
python -m http.server 8000
```

## Deploy

Push to the `main` branch. GitHub Pages publishes it automatically.
